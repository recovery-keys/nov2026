## Run backup commands:

```
# backup common + images:

duplicity --encrypt-key KEYYYYYYYY /home/USER/.local/share/Cryptomator/mnt/l1-data/ "file:///media/USER/backups/layer_I/ver.10/" --dry-run

```

## exporting keys : 
- use the above table to generate the password for the key:

```
gpg --export -a KEYYYYYYYY > bk_v10-l1_pub.key

gpg --export-secret-key -a KEYYYYYYYY > bk_v10-l1_sec.key

```
## removing keys:
```
gpg --delete-key KEYYYYYYYY
gpg --delete-secret-key KEYYYYYYYY
```

## importing the keys:
```
gpg --import bk_v10-l1_pub.asc
gpg --import bk_v10-l1_sec.asc
```
